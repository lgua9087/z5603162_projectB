pipeline, generate the report, and perform automated and visual QA. The student
set the scope: inspect Week 2 without running it, build the app first, finish the
project inside this directory, and defer deployment.

The curated logs are:

- `01_app_first_build.md` — static sample review, app architecture, and UI tests.
- `02_model_audit.md` — funds, VADER, fusion, and two material timing/execution
  corrections discovered during audit.
- `03_report_and_qa.md` — evidence-driven report generation and page-level QA.
- `04_evidence_strengthening.md` — sentiment predictiveness, combined-fund risk,
  robustness, commercial interpretation, and report revisions.
- `AI_NOTES.md` — consolidated attribution, limitations, and human actions left.

The original blank prompt template has been replaced by these completed
records. They describe what the assistant did and do not manufacture student
review that has not yet happened.
